# Frontend v20

Interface da mesa e do hub de campanhas.

Novidades:
- criação por template, em branco ou PDF;
- seleção dinâmica de heróis por campanha;
- editor de campanha e sessões;
- gerenciamento de heróis e vilões;
- upload de imagens e fichas em PDF;
- templates editáveis sem alterar o original.

Para testar todas as funções, acesse pelo backend em `http://localhost:3000`.
